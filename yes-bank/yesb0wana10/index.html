How the code YESB0WANA10 is built

YESB is the bank part: the letters of Yes Bank. The fifth character is always the digit 0. WANA10 is the part that names this branch.

The MICR code 442889005 is the number printed along the bottom of this branch's cheques. 442 is the city (the same three digits that begin the PIN code 442102), 889 is the bank and 005 is the branch.
