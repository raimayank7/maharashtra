How the code YESB0BHN008 is built

YESB is the bank part: the letters of Yes Bank. The fifth character is always the digit 0. BHN008 is the part that names this branch.

The MICR code 441822109 is the number printed along the bottom of this branch's cheques. 441 is the city (the same three digits that begin the PIN code 441906), 822 is the bank and 109 is the branch.
