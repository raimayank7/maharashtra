How the code JJSB0000038 is built

JJSB is the bank part: the letters of Jalgaon Janata Bank. The fifth character is always the digit 0. 000038 is the part that names this branch.

The MICR code 425507010 is the number printed along the bottom of this branch's cheques. 425 is the city (the same three digits that begin the PIN code 425001), 507 is the bank and 010 is the branch.
