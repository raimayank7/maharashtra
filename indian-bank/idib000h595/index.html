How the code IDIB000H595 is built

IDIB is the bank part: the letters of Indian Bank. The fifth character is always the digit 0. 00H595 is the part that names this branch.

The MICR code 440019011 is the number printed along the bottom of this branch's cheques. 440 is the city (the same three digits that begin the PIN code 440024), 019 is the bank and 011 is the branch.
