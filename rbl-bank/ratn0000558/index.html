How the code RATN0000558 is built

RATN is the bank part: the letters of RBL Bank. The fifth character is always the digit 0. 000558 is the part that names this branch.

The MICR code 411176029 is the number printed along the bottom of this branch's cheques. 411 is the city (the same three digits that begin the PIN code 411018), 176 is the bank and 029 is the branch.
