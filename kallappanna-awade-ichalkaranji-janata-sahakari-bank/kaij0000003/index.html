How the code KAIJ0000003 is built

KAIJ is the bank part: the letters of Kallappanna Awade Ichalkaranji Janata Sahakari Bank. The fifth character is always the digit 0. 000003 is the part that names this branch.

The MICR code 416386501 is the number printed along the bottom of this branch's cheques. 416 is the city (the same three digits that begin the PIN code 416103), 386 is the bank and 501 is the branch.
