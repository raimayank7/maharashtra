How the code SJSB0000019 is built

SJSB is the bank part: the letters of Solapur Janata Sahakari Bank. The fifth character is always the digit 0. 000019 is the part that names this branch.

The MICR code 413587352 is the number printed along the bottom of this branch's cheques. 413 is the city (the same three digits that begin the PIN code 413307), 587 is the bank and 352 is the branch.
