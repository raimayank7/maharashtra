How the code APBL0001001 is built

APBL is the bank part: these are the letters of Andhra Pradesh State Co-operative Bank. District Co-operative Central Bank Srikakul sends and receives payments through that bank, so its codes carry those letters. The fifth character is always the digit 0. 001001 is the part that names this branch.

The MICR code 532852002 is the number printed along the bottom of this branch's cheques. 532 is the city (the same three digits that begin the PIN code 532001), 852 is the bank and 002 is the branch.
