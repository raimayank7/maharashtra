How the code UTIB0SHUCBH is built

UTIB is the bank part: these are the letters of Axis Bank. Hadagali Urban Co-operative Bank sends and receives payments through that bank, so its codes carry those letters. The fifth character is always the digit 0. SHUCBH is the part that names this branch.

The MICR code 583913502 is the number printed along the bottom of this branch's cheques. 583 is the city (the same three digits that begin the PIN code 583219), 913 is the bank and 502 is the branch.
