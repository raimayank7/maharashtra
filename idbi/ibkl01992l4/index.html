How the code IBKL01992L4 is built

IBKL is the bank part: the letters of IDBI. The fifth character is always the digit 0. 1992L4 is the part that names this branch.

The MICR code 423819352 is the number printed along the bottom of this branch's cheques. 423 is the city (the same three digits that begin the PIN code 423401), 819 is the bank and 352 is the branch.
