How the code IBKL0487SL1 is built

IBKL is the bank part: the letters of IDBI. The fifth character is always the digit 0. 487SL1 is the part that names this branch.

The MICR code 416942151 is the number printed along the bottom of this branch's cheques. 416 is the city (the same three digits that begin the PIN code 416416), 942 is the bank and 151 is the branch.
