How the code UTIB0SCPSBN is built

UTIB is the bank part: these are the letters of Axis Bank. Chikmagalur Pattana Sahakara Bank Niyamitha sends and receives payments through that bank, so its codes carry those letters. The fifth character is always the digit 0. SCPSBN is the part that names this branch.

The MICR code 577815102 is the number printed along the bottom of this branch's cheques. 577 is the city (the same three digits that begin the PIN code 577101), 815 is the bank and 102 is the branch.
