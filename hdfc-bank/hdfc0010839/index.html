How the code HDFC0010839 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 010839 is the part that names this branch.

The MICR code 441240010 is the number printed along the bottom of this branch's cheques. 441 is the city (the same three digits that begin the PIN code 441108), 240 is the bank and 010 is the branch.
