How the code UJVN0004436 is built

UJVN is the bank part: the letters of Ujjivan Small Finance Bank. The fifth character is always the digit 0. 004436 is the part that names this branch.

The MICR code 400761015 is the number printed along the bottom of this branch's cheques. 400 is the city (the same three digits that begin the PIN code 400022), 761 is the bank and 015 is the branch.
