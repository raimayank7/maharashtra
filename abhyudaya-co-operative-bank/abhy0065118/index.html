How the code ABHY0065118 is built

ABHY is the bank part: the letters of Abhyudaya Co-operative Bank. The fifth character is always the digit 0. 065118 is the part that names this branch.

The MICR code 422065004 is the number printed along the bottom of this branch's cheques. 422 is the city (the same three digits that begin the PIN code 422101), 065 is the bank and 004 is the branch.
