How the code UTIB0002911 is built

UTIB is the bank part: the letters of Axis Bank. The fifth character is always the digit 0. 002911 is the part that names this branch.

The MICR code 440211015 is the number printed along the bottom of this branch's cheques. 440 is the city (the same three digits that begin the PIN code 440013), 211 is the bank and 015 is the branch.
